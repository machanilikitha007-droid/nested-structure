# Nested Structure

## Author
M.Likitha

## Description
This program demonstrates a nested structure in C.

The Student structure contains another structure called
Address. The Address structure stores the city and pincode
of the student.

## Concepts Used
- Structure
- Nested structure
- Structure members
- Structure member access
- Initialization of nested structures

## How to Run

gcc nested_structure.c -o nested_structure

./nested_structure

## Sample Output

Student Details
Roll Number: 101
Name: Likitha
City: Anantapur
Pincode: 515001
